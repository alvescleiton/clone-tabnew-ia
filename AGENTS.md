# AGENTS.md

## Sobre o projeto

Clone do [TabNews](https://tabnews.com.br), desenvolvido para o curso [curso.dev](https://curso.dev) com o auxílio de agentes de IA.

Repositório: https://github.com/alvescleiton/clone-tabnew-ia

## Stack

- Next.js (App Router, pasta `app/`)
- React
- JavaScript (sem TypeScript)

As versões exatas estão no `package.json`.

## Comandos

- `npm run dev`: inicia o servidor de desenvolvimento
- `npm run build`: gera o build de produção
- `npm start`: roda o build de produção
